英语面试健身房 · Windows 免安装版
================================

【快速开始】
1. 把本文件夹解压到任意位置（建议路径不含特殊字符）。
2. 双击 EnglishInterviewGym.exe。
   · 会打开一个独立的应用窗口「英语面试健身房」（无黑色控制台窗口）；
   · 关闭该窗口 = 退出程序（数据已自动保存）。
3. 首次使用：在窗口里点「⚙️ 设置」（或顶部黄色提示条），填好三项——
     · API 接口地址（Base URL，任何 OpenAI 兼容服务均可）
     · API Key
     · 对话模型
   点「保存并生效」即可开始练习。
   语音识别 / 语音合成的端点与模型在「进阶设置」里，按你的服务商文档填写。
4. 退出方式：直接关闭应用窗口；或在「⚙️ 设置 → 完全退出程序」里点一下。

【兼容性说明】
· 应用窗口使用系统自带的 WebView2 内核（Win11 及更新过的 Win10 均自备）。
· 万一系统缺少 WebView2：程序会自动改用 Edge/Chrome 独立窗口或浏览器打开界面，
  退出请使用「⚙️ 设置 → 完全退出程序」。
· 运行日志：logs/app.log（出问题时把它发给我们即可定位）。

【数据与配置】
· 全部保存在本文件夹内：data/（训练数据）、.env（API Key）、
  config.local.yaml（界面里保存的设置）、materials/（题库/人格/简历等）。
· 复制整个文件夹 = 完整迁移；删除文件夹 = 完全卸载。

【常见问题】
· 窗口没出现：稍等几秒；若仍无窗口，查看 logs/app.log 排查。
· 录音没反应：浏览器会请求麦克风权限，点「允许」；若误点了拒绝，
  请在权限设置里改为允许后刷新界面。
· 杀毒软件误报：PyInstaller 打包的程序偶被误判，可添加信任；
  不放心时也可改用源码方式运行（见仓库 README）。
· 系统要求：Windows 10 / 11（64 位）。
