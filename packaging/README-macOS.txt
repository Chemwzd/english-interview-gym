英语面试健身房 · macOS 免安装包（Apple Silicon）
=================================================

【快速开始】
1. 解压到任意文件夹（放用户目录即可，别放 iCloud 同步目录里跑）。
   · 建议用系统自带解压：访达里直接双击 zip；或终端：ditto -x -k 安装包.zip .
2. 双击「启动.command」启动 —— 会自动去除系统"隔离"标记，无需其他操作。
   · 首次启动若被 macOS 拦（提示未签名）：右键点「启动.command」→ 打开 → 再确认「打开」。
   · ⚠️ 若弹出『"……"已损坏，无法打开。你应该将它移到废纸篓。』一类对话框：
       请点【取消】，不要点"移到废纸篓"！—— 这是 macOS 对未签名应用的拦截提示，
       点"移到废纸篓"会把程序文件删掉。
       （v0.15.11 起安装包已做全面兼容，正常使用不会再出现该弹窗；
         万一文件已被误删：重新解压即可 —— 已在练习的话，先把 data/ 文件夹拷出来，解压后放回。）
3. 浏览器自动打开 http://127.0.0.1:8765 。
4. 首次使用：点「⚙️ 设置」→ 分别填好「对话服务」与「语音服务」→「保存并生效」。
5. 关闭终端窗口 = 停止服务；也可在「⚙️ 设置 → ⏻ 完全退出程序」退出。

【手机访问】
「⚙️ 设置 → 📱 手机访问 → 启用」：自动生成证书并开启 HTTPS 通道；
手机端安装证书与添加到主屏幕的步骤，界面上有完整指引。

【数据与配置】
全部保存在本文件夹内：data/（训练数据）、.env（API Key）、
config.local.yaml（界面设置）、materials/（题库/人格/简历）、certs/（手机访问证书）。
复制文件夹 = 完整迁移；删除文件夹 = 卸载。

【系统要求】
macOS 12+，Apple Silicon（M 系列）。Intel 机型请改用源码方式运行（见仓库 README）。
本包为未签名开发版（ad-hoc 签名），按上面步骤放行即可。
