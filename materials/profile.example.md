# 个人资料（示例模板）

> 用法：复制本文件为 `profile.md`，或直接在 App 首页点「📄 我的简历」导入 docx/pdf/txt。
> App 会用这份资料生成「🎯 定制版」示范答案与个性化反馈。
> ⚠️ `profile.md` 已被 `.gitignore` 忽略，不会被提交到任何仓库。

建议包含（也可直接粘贴完整简历文本）：

- **身份**：<例如：XX 专业博士候选人 / 5 年经验的软件工程师>
- **方向**：<你的领域 × 核心技术关键词>
- **代表项目**：<项目名> —— 解决什么问题，用什么方法，结果数字
- **代表成果**：<论文 / 产品 / 开源项目 + 量化结果>
- **目标岗位**：<行业 + 城市 + 岗位类型>

注意：不要在资料里写入涉密或不可公开的信息——它会进入示范答案的生成上下文。
