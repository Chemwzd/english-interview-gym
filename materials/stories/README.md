# 故事库（Story Bank）

面试高分的关键不是"题库背了多少"，而是**你有 5–8 个可以被打磨到极致、经得起连续追问的个人故事**。本目录用于存放你自己的故事文件（公开仓库中不包含任何示例故事）。

## 怎么用

1. 复制 `template.md` 为 `01-<故事名>.md`、`02-...`，每篇一个故事（研究/项目/失败/协作/动机…）；
2. 每个故事固定结构：一句话主旨 → 适用问题 → 中文素材 → 英文要点句（背这句）→ 数字清单 → 追问雷区；
3. 练题时优先用"你有故事"的题目；AI Feedback 里的 Correction/Upgrade 也定期沉淀回对应故事；
4. 故事越精炼越好：**一个故事讲 30–45 秒，配 2–3 个可支撑追问的数字**。

`template.md` 是空白模板，直接复制使用。
