# 训练计划（前 4 周 · 每日 20 分钟）

> 系统：http://127.0.0.1:8765 （`bash scripts/run_server.sh` 启动）
> 建议先用「基线 8 题」拿一份语速/停顿/填充词基线，再按下述节奏推进。

## 第 0 周（开始前）

- [ ] 跑一次「基线 8 题」，读复盘报告里的语速(wpm)/长停顿/填充词数字
- [ ] 建故事库：用 `materials/stories/template.md` 写 3–5 个自己的故事（每个带 2–3 个具体数字）
- [ ] 挑 2–3 道最可能被问的题：先「照读」通用版示范答案找节奏 → 再「自己说」

## 第 1–2 周 · 打底

每日 20 分钟 = 10 分钟练 + 5 分钟复盘 + 5 分钟背要点

- 每天 1 道技术/专业深挖题：照读 → 自由说 → 读 AI Feedback 的 Correction / Revision
- 把好用的新表达点词收藏；反复出现的问题交给错题本
- 周末：一次 3 题连练（技术官人格，自由说）

## 第 3–4 周 · 行为面与商务英语

- 行为面按 STAR 练：领导力 / 团队 / 冲突 / 失败 / 压力，各至少 1 题
- 商务沟通题练「结论先行」：30 秒版 + 90 秒版各来一遍
- 每周一次「压力面」人格加练；复盘时和首周基线数字对比

## 持续（第 2 个月起）

- 每天 1–2 题滚动复习：优先重练分数低的题，看每题详情里的趋势曲线
- 简历有更新就重新导入，示范答案的「定制版」会跟着迭代
